# Google Analytics Project

## Project Overview

This project focuses on analyzing website traffic data to understand user engagement, acquisition trends, regional performance, and traffic-source performance.

More than **100,000 website traffic records** were processed and analyzed using **Google Analytics API, Python, and MySQL**. The analyzed data was visualized through interactive dashboards developed using **Tableau and Apache Superset**.

Analysis was performed across **15+ user metrics** to identify high-engagement markets and generate meaningful audience insights.

## Tools & Technologies

- Google Analytics
- Google Analytics API
- Python
- MySQL
- Tableau
- Apache Superset

## Data Processing and Analysis

Website traffic data was obtained using the **Google Analytics API** and processed using **Python**.

The processed data was stored and queried using **MySQL** to evaluate user engagement and acquisition trends across more than **100,000 website traffic records**.

## Regional and Traffic Source Analysis

Regional and traffic-source analysis was performed across **15+ user metrics** to understand:

- User engagement trends
- User acquisition patterns
- Regional website performance
- Traffic-source performance
- High-engagement markets

The analysis helped identify high-engagement regions and provided better insights into website audiences and acquisition sources.

## Dashboard Development

Interactive dashboards were developed using **Tableau and Apache Superset** to visualize key website performance metrics.

The dashboards enabled faster analysis of engagement, acquisition, regional, and traffic-source trends while reducing manual reporting effort by approximately **50%**.

## Key Outcomes

- Processed and analyzed **100,000+ website traffic records**
- Evaluated user engagement and acquisition trends
- Conducted regional and traffic-source analysis across **15+ user metrics**
- Identified high-engagement markets
- Developed interactive dashboards using **Tableau and Apache Superset**
- Reduced manual reporting effort by approximately **50%**
